# IRIS 项目架构总览

## 一、项目一句话定位

**IRIS** = 一个用 Flutter 写的「跨平台万能视频播放器」，支持本地/WebDAV/FTP 三种文件来源，内置两套播放引擎可切换。

类比：它就像一个"视频界的文件管理器 + 播放器"，既能浏览远程文件，又能播放。

**类比理解**：整个 App 就像一家餐厅——
- **Pages** 是"包厢"（Home 包厢、Player 包厢）
- **Widgets** 是"餐具"（可复用的按钮、对话框、弹窗）
- **Hooks** 是"厨师的技能"（手势处理、音量控制、播放器操作）
- **Store** 是"仓库"（所有食材/数据集中管理）

## 三、核心数据流

```
用户操作          Hook 处理逻辑         Store 更新状态        UI 自动刷新
  │                  │                    │                    │
  │  点击播放按钮     │                    │                    │
  ├─────────────────►│  usePlayer         │                    │
  │                  ├───────────────────►│  PlayQueueStore    │
  │                  │  调用 store 方法    │  .setCurrentIndex()│
  │                  │                    ├───────────────────►│
  │                  │                    │  Widget 重新 build │
  │                  │                    │                    │
  │  拖动进度条       │                    │                    │
  ├─────────────────►│  useMediaPlayer    │                    │
  │                  │  .seek()           │                    │
  │                  │                    │                    │
  │  切换全屏         │                    │                    │
  ├─────────────────►│  useFullScreen     │                    │
  │                  ├───────────────────►│  PlayerUiStore     │
  │                  │                    │  .setFullScreen()  │
  │                  │                    ├───────────────────►│
  │                  │                    │                    │
  ▼                  ▼                    ▼                    ▼
```

**关键点**：状态是单向流动的——`用户 → Hook → Store → UI`，没有乱窜的回调。

## 四、播放器架构（最核心的设计）

这是整个项目最巧妙的地方——**策略模式**：

```
                    ┌─────────────────────┐
                    │   MediaPlayer       │
                    │   (抽象接口)          │
                    │                     │
                    │  • play()           │
                    │  • pause()          │
                    │  • seek()           │
                    │  • setVolume()      │
                    │  • setSpeed()       │
                    └──────────┬──────────┘
                               │
              ┌────────────────┴────────────────┐
              ▼                                 ▼
    ┌──────────────────┐              ┌──────────────────┐
    │ MediaKitPlayer   │              │    FvpPlayer     │
    │  (mpv 引擎)       │              │  (FFmpeg 引擎)   │
    │                  │              │                  │
    │  • 字幕支持好     │              │  • 轻量          │
    │  • 功能全        │              │  • 实验性         │
    │  • 主力引擎      │              │                  │
    └──────────────────┘              └──────────────────┘

    切换方式：AppStore.playerBackend = "mediaKit" | "fvp"
```

**类比**：就像你车里的驾驶模式（运动/舒适），底层引擎不同，但方向盘（接口）一样。

## 七、页面导航方式

这个项目**没有用路由库**，而是用原生 Flutter 的方式：

```
┌─────────────────────────────────────────────────────┐
│                    导航方式                           │
│                                                     │
│  1. Navigator.push(Popup(...))                      │
│     └── 侧边弹出面板（设置、历史、播放队列）            │
│                                                     │
│  2. showDialog()                                    │
│     └── 模态对话框（添加 WebDAV、FTP、语言选择）       │
│                                                     │
│  3. showModalBottomSheet()                          │
│     └── 底部弹出（打开链接）                          │
│                                                     │
│  4. 直接 Widget 组合                                 │
│     └── Home → PlayerView（无跳转，直接替换）         │
└─────────────────────────────────────────────────────┘
```

## 八、代码生成体系

```
  你写的代码                    build_runner 生成
  ┌─────────────┐              ┌──────────────────┐
  │ @freezed    │              │ *.freezed.dart   │
  │ class Foo   │  ─────────►  │ (不可变数据类)    │
  │ { ... }     │              │ copyWith/equality│
  └─────────────┘              └──────────────────┘

  ┌─────────────┐              ┌──────────────────┐
  │ @JsonSerializable          │ *.g.dart         │
  │ class Bar   │  ─────────►  │ (JSON 序列化)     │
  │ { ... }     │              │ fromJson/toJson  │
  └─────────────┘              └──────────────────┘
```

**记住**：改了 `models/` 或 `store/` 下的类，必须跑 `flutter pub run build_runner build`。

## 九、技术栈速查表

| 层次 | 技术选型 | 作用 |
|------|---------|------|
| 状态管理 | `flutter_zustand` + `flutter_hooks` | 类 React 的 hooks 风格状态管理 |
| 持久化 | `FlutterSecureStorage` | 加密本地存储 |
| 播放器 | `media_kit`(mpv) + `fvp`(FFmpeg) | 双引擎可切换 |
| 网络存储 | `webdav_client` + `pure_ftp` | 远程文件访问 |
| 代码生成 | `freezed` + `json_serializable` | 不可变模型 + JSON 序列化 |
| 窗口管理 | `window_manager` + `window_size` | 桌面端窗口控制 |
| 国际化 | ARB 文件 + `intl` | 中英文支持 |

```

    ├─ 1. 初始化 globals（CLI 参数解析）
    │
    ├─ 2. Provider 注入 MediaPlayer 实例

                │

                        │
                        └─ 点击文件 → Navigator.push → Player 页面
```

## 总结：理解这个项目的 5 个关键

1. **Hooks + Zustand**：所有 Widget 都是 `HookWidget`，状态通过 `useXxxStore()` 读取
2. **策略模式**：播放器是接口，两套实现可热切换
3. **持久化分离**：4 个 Store 持久化，1 个（PlayerUi）不持久化
4. **无路由**：用原生 Navigator + Popup/Dialog 组合
5. **Freezed 一切**：所有数据模型都是不可变的，改了要跑 build_runner
