# IRIS 源管理实施计划

> 参照 Legado 书源管理，为 IRIS 视频播放器构建完整的源管理体系。

## 当前状态

已完成功能：

- [x] `VideoSource` 数据模型（id/name/apiUrl/type/jiexiUrl/isNsfw/status/group/weight/header/comment/lastUpdateTime/respondTime）
- [x] `SourceStore` 持久化存储（Hive，增删改查 + 分组 CRUD）
- [x] `SourcesPage` 基础 UI（列表、搜索栏、状态筛选、分组筛选、添加表单）
- [x] FFI 绑定层（`lib/ffi/`，legado_ffi.dll 的 Dart 封装）
- [x] 排序功能（6 种排序方式 + 升序/降序）
- [x] 源导入导出（本地 JSON 文件，合并/替换模式）
- [x] 源测试（单个 + 批量，HTTP 请求检测可用性和响应时间）
- [x] 源编辑页面（双 Tab：基础信息 + 高级配置）
- [x] 订阅管理（URL 订阅、单个/批量同步、同步状态追踪）
- [x] FFI 规则集成（SourceRule 模型 + SourceParser 解析器 + 规则编辑 Tab）

## 步骤 10：FFI 规则集成 ✅

### 目标

利用 `legado_ffi` 的解析引擎，根据源的规则配置解析网页内容。

### 已完成功能

- ✅ `SourceRule` 数据模型（Freezed），包含：
  - HTML 选择器规则（列表/名称/链接/封面/年份/地区/类型/评分/详情/播放列表）
  - 搜索规则（URL 模板 + 结果列表选择器）
  - MacCMS JSON 字段映射（10 个字段：listPath/id/name/cover/playUrl/year/area/type/desc/score）
  - 解析配置（WebView/请求头/Cookie）
- ✅ `VideoSource` 添加 `rule` 字段
- ✅ `SourceParser` 解析器类，封装 FFI 调用：
  - `parseList()` — 解析视频列表（MacCMS JSON / HTML 双模式）
  - `parseDetail()` — 解析详情页（简介 + 播放链接）
  - `parseSearch()` — 解析搜索结果
  - `getSearchUrl()` — 生成搜索 URL
  - MacCMS 播放链接格式解析（`线路$url#url$$$线路$url#url`）
- ✅ 编辑页面新增"规则"Tab：
  - 搜索规则区（URL 模板 + 列表选择器）
  - HTML 选择器区（9 个字段）
  - 详情/播放规则区（4 个字段）
  - MacCMS JSON 字段映射区（10 个字段）
  - 根据源类型自动显示对应配置

### 涉及文件

- `lib/models/source_rule.dart` — 规则数据模型（Freezed）
- `lib/models/video_source.dart` — 添加 `rule` 字段
- `lib/utils/source_parser.dart` — FFI 规则解析器
- `lib/pages/sources/source_edit_page.dart` — 新增规则 Tab
- `lib/ffi/ffi.dart` — 已完成的 FFI 绑定

## 建议实施顺序

```
4 → 5 → 6 → 7 → 8 → 9 → 10
```

- **步骤 4-5**：列表交互增强，纯 UI 改动
- **步骤 6-7**：导入导出和校验，需要网络请求
- **步骤 8**：独立编辑页，工作量较大
- **步骤 9-10**：订阅和 FFI 规则，属于高级功能
