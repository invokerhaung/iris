# IRIS 源管理 vs Legado 书源管理 对比分析

## 一、功能对比总览

| 功能维度 | IRIS 源管理 | Legado 书源管理 |
|---------|------------|----------------|
| **内容类型** | 视频源 | 书源（文本/音频/图片/文件） |
| **技术栈** | Flutter + FFI (Go) | Kotlin + Room + Coroutines |
| **状态管理** | Zustand + Hive | ViewModel + Room + Flow |
| **解析引擎** | LegadoAnalyzer (FFI) | AnalyzeRule (JSoup/JsonPath/XPath/Rhino) |
| **批量操作** | ❌ 待实现 | ✅ 完整支持 |
| **拖拽排序** | ❌ 不支持 | ✅ 支持 |
| **订阅管理** | ✅ 支持 | ❌ 不支持 |
| **源校验** | ✅ 简单测试 | ✅ 完整校验流程 |
| **登录支持** | ❌ 不支持 | ✅ 完整支持 |
| **并发控制** | ❌ 不支持 | ✅ 并发率限制 |

## 二、数据结构对比

### 2.1 核心模型字段对比

| 字段类别 | IRIS VideoSource | Legado BookSource |
|---------|------------------|-------------------|
| **基础标识** | `id` (UUID), `apiUrl` | `bookSourceUrl` (主键) |
| **名称** | `name` | `bookSourceName` |
| **分组** | `group` (单分组) | `bookSourceGroup` (逗号分隔多分组) |
| **权重** | `weight` | `weight` |
| **状态** | `status` (active/inactive/error) | `enabled` + `enabledExplore` (双状态) |
| **请求头** | `header` | `header` |
| **备注** | `comment` | `bookSourceComment` |
| **响应时间** | `respondTime` | `respondTime` |
| **更新时间** | `lastUpdateTime` | `lastUpdateTime` |
| **NSFW标记** | `isNsfw` | ❌ 无 |
| **解析地址** | `jiexiUrl` | ❌ 无 |
| **类型** | ❌ 无 | `bookSourceType` (0文本/1音频/2图片/3文件) |
| **登录相关** | ❌ 无 | `loginUrl`, `loginUi`, `loginCheckJs` |
| **并发控制** | ❌ 无 | `concurrentRate`, `enabledCookieJar` |

### 2.2 规则结构对比

#### IRIS SourceRule（扁平结构）

```dart
class SourceRule {
  // 列表页规则
  String? ruleList;           // 列表选择器
  String? ruleName;           // 名称规则
  String? ruleUrl;            // 链接规则
  String? ruleCover;          // 封面规则
  String? ruleYear;           // 年份规则
  String? ruleArea;           // 地区规则
  String? ruleType;           // 类型规则
  String? ruleScore;          // 评分规则

  // 详情页规则
  String? ruleDetailDesc;     // 简介规则
  String? ruleDetailPlayList; // 播放列表选择器
  String? ruleDetailPlayName; // 播放项名称规则
  String? ruleDetailPlayUrl;  // 播放项链接规则

  // 搜索规则
  String? ruleSearchUrl;      // 搜索URL模板
  String? ruleSearchList;     // 搜索结果列表选择器

  // 配置
  bool? useWebView;
  String? customHeaders;
  String? cookie;
}
```

#### Legado BookSource（嵌套结构）

```kotlin
class BookSource {
  // 搜索规则
  var ruleSearch: SearchRule?   // 包含 bookList, name, author, bookUrl, coverUrl 等

  // 发现规则
  var ruleExplore: ExploreRule? // 包含 bookList, name, author, bookUrl, coverUrl 等

  // 详情规则
  var ruleBookInfo: BookInfoRule? // 包含 name, author, coverUrl, intro, tocUrl 等

  // 目录规则
  var ruleToc: TocRule?         // 包含 chapterList, chapterName, chapterUrl 等

  // 正文规则
  var ruleContent: ContentRule? // 包含 content, title, nextContentUrl, replaceRegex 等

  // 搜索/发现URL模板
  var searchUrl: String?
  var exploreUrl: String?
}
```

**关键差异：**
- Legado 有独立的**发现规则**（ExploreRule），IRIS 没有
- Legado 有**目录规则**（TocRule）和**正文规则**（ContentRule），IRIS 用**播放列表规则**替代
- Legado 规则是嵌套对象，IRIS 是扁平结构

## 三、功能差异详解

### 3.1 IRIS 独有功能

| 功能 | 说明 |
|-----|------|
| **订阅管理** | 支持添加远程订阅源，自动同步更新 |
| **NSFW标记** | 可标记成人内容源 |
| **解析地址(jiexiUrl)** | 支持第三方解析服务 |
| **视频元数据规则** | year/area/type/score 等视频特有字段 |

### 3.2 Legado 独有功能

| 功能 | 说明 |
|-----|------|
| **批量操作** | 多选、全选/反选、批量删除/启用/禁用/导出 |
| **拖拽排序** | 手动拖拽调整顺序 |
| **发现功能** | 分类浏览（热门、最新、排行等） |
| **完整校验流程** | 使用 checkKeyWord 搜索校验，自动标记失效源 |
| **登录支持** | loginUrl + loginUi + loginCheckJs |
| **并发控制** | concurrentRate 限制并发请求 |
| **Cookie管理** | enabledCookieJar 自动保存Cookie |
| **JS执行** | 支持 @js: 前缀的 JavaScript 规则 |
| **多类型支持** | 文本/音频/图片/文件四种类型 |
| **分页支持** | nextTocUrl（目录分页）、nextContentUrl（正文分页） |
| **内容替换** | replaceRegex 正则替换净化 |
| **分享功能** | 书源分享 |

### 3.3 功能实现差异

| 功能 | IRIS 实现 | Legado 实现 |
|-----|----------|-------------|
| **存储** | Hive (JSON序列化) | Room (SQLite) |
| **导入** | 文件选择器 + JSON解析 | 文件选择器 + URL输入 + 预览确认 |
| **导出** | 导出到文件 | 导出选中 + 分享 |
| **测试** | 简单HTTP GET | 完整搜索校验流程 |
| **排序** | 6种排序方式 | 7种排序 + 拖拽 |
| **筛选** | 状态 + 分组 | 状态 + 分组 + 域名 + 登录状态 |

## 四、解析引擎对比

### 4.1 规则语法

| 语法类型 | IRIS (LegadoAnalyzer) | Legado (AnalyzeRule) |
|---------|----------------------|---------------------|
| **CSS选择器** | ✅ `.class`, `tag`, `a@href` | ✅ JSoup 选择器 |
| **属性提取** | ✅ `a@href`, `img@src` | ✅ `@attr` 语法 |
| **文本提取** | ✅ `h1@text` | ✅ `@text` 语法 |
| **组合选择器** | ✅ `body&&.list a` | ✅ `&&` 连接 |
| **JsonPath** | ❌ 不支持 | ✅ `$.data.books` |
| **XPath** | ❌ 不支持 | ✅ `//div[@class]` |
| **JavaScript** | ✅ 通过 LegadoJS | ✅ Rhino 引擎 |
| **正则替换** | ❌ 不支持 | ✅ `##regex` 语法 |
| **备用规则** | ❌ 不支持 | ✅ `rule1||rule2` |

### 4.2 实现方式

**IRIS：**
```
Dart → FFI调用 → legado_ffi.dll (Go) → LegadoAnalyzer
```

**Legado：**
```
Kotlin → AnalyzeRule → JSoup / JsonPath / XPath / Rhino
```

**关键发现：** IRIS 的 FFI 库是从 Legado 移植而来，核心 CSS 选择器解析逻辑相同，但功能简化。

## 五、源通用性分析

### 5.1 JSON 格式兼容性

#### Legado 书源 JSON 示例
```json
{
  "bookSourceUrl": "https://example.com",
  "bookSourceName": "示例源",
  "bookSourceType": 0,
  "enabled": true,
  "enabledExplore": true,
  "searchUrl": "https://example.com/search?keyword={{key}}",
  "ruleSearch": {
    "bookList": ".book-item",
    "name": "h3@text",
    "author": ".author@text",
    "bookUrl": "a@href",
    "coverUrl": "img@src"
  },
  "ruleBookInfo": {
    "name": "h1@text",
    "intro": ".intro@text",
    "tocUrl": "a.toc@href"
  },
  "ruleToc": {
    "chapterList": ".chapter-list li",
    "chapterName": "a@text",
    "chapterUrl": "a@href"
  },
  "ruleContent": {
    "content": ".content@text"
  }
}
```

#### IRIS 源 JSON 示例
```json
{
  "id": "uuid-xxx",
  "name": "示例源",
  "apiUrl": "https://example.com",
  "status": "active",
  "rule": {
    "ruleList": ".video-item",
    "ruleName": "h3@text",
    "ruleUrl": "a@href",
    "ruleCover": "img@src",
    "ruleSearchUrl": "https://example.com/search?keyword={keyword}",
    "ruleSearchList": ".search-result .item",
    "ruleDetailDesc": ".desc@text",
    "ruleDetailPlayList": ".play-list li",
    "ruleDetailPlayName": "a@text",
    "ruleDetailPlayUrl": "a@href"
  }
}
```

### 5.2 字段映射关系

| Legado 字段 | IRIS 对应字段 | 兼容性 |
|------------|--------------|--------|
| `bookSourceUrl` | `apiUrl` | ✅ 可映射 |
| `bookSourceName` | `name` | ✅ 可映射 |
| `enabled` | `status` | ✅ 可映射 |
| `weight` | `weight` | ✅ 完全兼容 |
| `header` | `header` | ✅ 完全兼容 |
| `bookSourceComment` | `comment` | ✅ 可映射 |
| `searchUrl` | `ruleSearchUrl` | ✅ 可映射（需转换占位符） |
| `ruleSearch.bookList` | `ruleSearchList` | ✅ 可映射 |
| `ruleSearch.name` | `ruleName` | ✅ 可映射 |
| `ruleSearch.bookUrl` | `ruleUrl` | ✅ 可映射 |
| `ruleSearch.coverUrl` | `ruleCover` | ✅ 可映射 |
| `ruleBookInfo.intro` | `ruleDetailDesc` | ✅ 可映射 |
| `ruleToc.chapterList` | `ruleDetailPlayList` | ✅ 可映射（语义不同） |
| `ruleToc.chapterUrl` | `ruleDetailPlayUrl` | ✅ 可映射（语义不同） |
| `ruleContent.content` | ❌ 无对应 | ❌ 不兼容 |
| `ruleExplore.*` | ❌ 无对应 | ❌ 不兼容 |
| `bookSourceType` | ❌ 无对应 | ❌ 不兼容 |
| `loginUrl` | ❌ 无对应 | ❌ 不兼容 |

### 5.3 通用性结论

#### ✅ 可以通用的部分

1. **基础列表源**：只包含搜索和列表规则的简单书源
2. **CSS选择器规则**：`.class`, `tag`, `a@href` 等基础语法
3. **搜索功能**：searchUrl + ruleSearch 的基本映射

#### ❌ 不能通用的部分

1. **发现源**：Legado 的 ExploreRule 在 IRIS 中无对应
2. **阅读源**：Legado 的 TocRule + ContentRule 无法映射到视频播放
3. **复杂规则**：JsonPath、XPath、正则替换等高级语法
4. **JS规则**：@js: 前缀的 JavaScript 规则
5. **多类型源**：音频/图片/文件类型源

### 5.4 实际可用性评估

| 场景 | 可用性 | 说明 |
|-----|--------|------|
| **视频网站搜索** | ⚠️ 部分可用 | 需要手动调整规则字段映射 |
| **视频网站详情** | ⚠️ 部分可用 | 需要将目录规则转为播放列表规则 |
| **纯搜索源** | ✅ 基本可用 | 基础字段可直接映射 |
| **复杂书源** | ❌ 不可用 | 规则结构差异太大 |

## 六、改进建议

### 6.1 IRIS 可借鉴的 Legado 功能

| 优先级 | 功能 | 预期收益 |
|-------|------|---------|
| **高** | 批量操作 | 提升管理效率 |
| **高** | 源校验完善 | 自动发现失效源 |
| **中** | 拖拽排序 | 提升用户体验 |
| **中** | 发现功能 | 内容探索能力 |
| **低** | 登录支持 | 扩展源覆盖范围 |
| **低** | 并发控制 | 避免被封禁 |

### 6.2 源格式兼容方案

如果需要支持 Legado 源导入，建议：

1. **创建转换器**：Legado JSON → IRIS VideoSource 映射
2. **字段映射表**：建立完整的字段对应关系
3. **规则适配**：将嵌套规则展平为 IRIS 扁平结构
4. **功能降级**：不支持的规则标记为不可用

```dart
// 示例：Legado 到 IRIS 的转换
VideoSource fromLegado(Map<String, dynamic> legado) {
  return VideoSource(
    apiUrl: legado['bookSourceUrl'],
    name: legado['bookSourceName'],
    status: legado['enabled'] == true ? SourceStatus.active : SourceStatus.inactive,
    weight: legado['weight'] ?? 0,
    header: legado['header'],
    comment: legado['bookSourceComment'],
    rule: SourceRule(
      ruleSearchUrl: legado['searchUrl']?.replaceAll('{{key}}', '{keyword}'),
      ruleSearchList: legado['ruleSearch']?['bookList'],
      ruleName: legado['ruleSearch']?['name'],
      ruleUrl: legado['ruleSearch']?['bookUrl'],
      ruleCover: legado['ruleSearch']?['coverUrl'],
      ruleDetailDesc: legado['ruleBookInfo']?['intro'],
      ruleDetailPlayList: legado['ruleToc']?['chapterList'],
      ruleDetailPlayUrl: legado['ruleToc']?['chapterUrl'],
    ),
  );
}
```

## 七、总结

### 核心差异

| 维度 | IRIS | Legado |
|-----|------|--------|
| **定位** | 视频播放器 | 阅读器 |
| **复杂度** | 中等 | 高 |
| **规则深度** | 2层（列表+详情） | 4层（搜索+发现+详情+目录+正文） |
| **扩展性** | 有限 | 强（JS支持） |
| **用户群体** | 视频爱好者 | 阅读爱好者 |

### 通用性结论

**部分通用，但需要适配：**
- 基础搜索源可直接映射
- 复杂书源需要手动调整
- 规则语法基础兼容（CSS选择器）
- 高级功能不兼容（JS、XPath、JsonPath）
