# 视频详情页和播放页实施计划

## 一、目标

根据 Legado 视频播放流程文档，为 IRIS 项目实现视频详情页和播放页，支持：

- 视频类型书籍点击后跳转到详情页
- 详情页显示视频信息和播放列表
- 点击播放列表项跳转到播放页
- Windows 横屏布局优化
- 其他类型书籍保持现有 AlertDialog 展示

---

## 二、数据流分析

### 现有架构

```
发现列表/搜索结果
    ↓ 点击
_onBookTap(book: ParsedBookItem)
    ↓
AlertDialog（临时实现）
```

### 目标架构

```
发现列表/搜索结果
    ↓ 点击
_onBookTap(book: ParsedBookItem, source: BookSource)
    ↓ 判断类型
    ├── video → VideoInfoPage(source, book)
    │           ↓ 加载详情 + 目录
    │           ↓ 点击章节
    │           └── VideoPlayPage(source, chapters, initialIndex)
    │               ↓ 使用现有播放器
    │               └── Player / PlayerView
    └── 其他 → AlertDialog（保持现有）
```

## 四、视频 URL 解析逻辑

根据文档，视频内容有三种格式：

### 4.1 JSON 格式

```json
{
  "header": {"Referer": "..."},
  "resolutions": [
    {"name": "720P", "url": "..."},
    {"name": "1080P", "url": "..."}
  ],
  "defaultIndex": 1
}
```

### 4.2 多分辨率格式

```
720P::https://example.com/video_720p.m3u8
1080P::https://example.com/video_1080p.m3u8
```

### 4.3 直接 URL

```
https://example.com/video.m3u8
```

### 解析实现

在 `SourceParser` 中新增方法：

```dart
/// 解析视频内容
VideoPlayInfo? parseVideoContent(String content) {
  // 1. 尝试 JSON 格式
  if (content.startsWith('{')) {
    return _parseJsonVideoSource(content);
  }

  // 2. 尝试多分辨率格式
  if (content.contains('::') && content.contains('\n')) {
    return _parseMultiResolution(content);
  }

  // 3. 直接 URL
  if (content.startsWith('http')) {
    return VideoPlayInfo(url: content);
  }

  return null;
}
```

## 五、新增数据模型

### 5.1 VideoPlayInfo

**文件位置**: `lib/models/video_play_info.dart`

```dart
/// 视频播放信息
class VideoPlayInfo {
  final String? url;                    // 单 URL
  final Map<String, String>? headers;   // 请求头
  final List<VideoResolution>? resolutions; // 多分辨率列表
  final int defaultIndex;               // 默认分辨率索引

  VideoPlayInfo({
    this.url,
    this.headers,
    this.resolutions,
    this.defaultIndex = 0,
  });
}

/// 视频分辨率
class VideoResolution {
  final String name;  // 如 "720P", "1080P"
  final String url;

  VideoResolution({required this.name, required this.url});
}
```

## 十、风险和注意事项

1. **视频源兼容性**: 不同视频源的 HTML 结构差异较大，需要充分测试
2. **播放器兼容性**: 现有播放器主要面向本地文件，网络视频可能需要额外配置
3. **Windows 全屏**: 需要与现有播放器的全屏逻辑协调
4. **状态管理**: 播放队列管理需要与现有 `PlayQueueStore` 协调
