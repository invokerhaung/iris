# 源管理功能总结

## 一、功能概述

源管理是 IRIS 视频播放器的核心功能之一，允许用户管理视频源（类似 Legado 书源），支持导入导出、规则解析、订阅同步等。该功能位于底部导航栏的第二个 Tab（云图标）。

**已完成（9/10）**：数据模型、分组管理、搜索筛选、排序、导入导出、源测试、源编辑、订阅管理、FFI 规则集成
**待实现（1/10）**：批量操作（长按多选、全选/反选、批量删除/启用/禁用/导出）

## 三、核心功能实现

### 3.1 数据模型 (`lib/models/`)

#### VideoSource (`video_source.dart`)
- **字段**：`id`, `name`, `apiUrl`, `jiexiUrl`(解析地址), `isNsfw`, `status`, `group`(分组), `weight`(权重), `header`(请求头), `comment`(备注), `lastUpdateTime`, `respondTime`, `rule`(解析规则)
- **枚举**：`SourceStatus` (active/inactive/error), `SourceSortBy` (weight/name/apiUrl/lastUpdateTime/respondTime/status)

#### SourceRule (`source_rule.dart`)
- **列表页规则**：`ruleList`, `ruleName`, `ruleUrl`, `ruleCover`, `ruleYear`, `ruleArea`, `ruleType`, `ruleScore`
- **详情页规则**：`ruleDetailDesc`, `ruleDetailPlayList`, `ruleDetailPlayName`, `ruleDetailPlayUrl`
- **搜索规则**：`ruleSearchUrl` (含 `{keyword}` 占位符), `ruleSearchList`
- **解析配置**：`useWebView`, `customHeaders`, `cookie`
- **选择器语法**：CSS 选择器、属性提取 (`a@href`)、文本提取 (`h1@text`)、组合选择器 (`body&&.list a`)

#### SourceSubscription (`source_subscription.dart`)
- **字段**：`name`(订阅名称), `url`(JSON源列表地址), `lastSyncTime`, `lastSyncSuccess`, `sourceCount`, `autoSync`

#### SourceState (`store/source_state.dart`)
- **聚合状态**：`sources`, `currentSourceIndex`, `groups`, `sortBy`, `sortAscending`, `subscriptions`

---

### 3.2 状态管理 (`lib/store/use_source_store.dart`)

**SourceStore** 继承自 `PersistentStore<SourceState>`，使用 Zustand 风格状态管理 + Hive 持久化。

#### 源 CRUD 操作
- `addSource(source)` — 自动 UUID
- `removeSource(index)` — 删除指定源
- `updateSource(index, source)` — 更新源信息
- `updateCurrentSourceIndex(index)` — 更新当前选中源

#### 分组管理
- `addGroup(name)` — 添加分组（去重）
- `removeGroup(name)` — 删除分组（清空关联源的 group）
- `renameGroup(old, new)` — 重命名分组
- `allGroups` — 获取所有分组
- `getSourcesByGroup(group)` — 按分组筛选源

#### 排序功能
- `setSortBy(sortBy)` — 设置排序方式
- `toggleSortDirection()` — 切换排序方向
- `getSortedSources()` — 获取排序后的源列表（支持 6 种排序方式，升降序）

#### 导入导出
- `exportSources()` — 导出为 Legado 书源 JSON 数组格式
- `importSources(jsonStr, {merge})` — 支持 Legado 数组/单对象/IRIS 完整格式，merge 模式按 apiUrl 去重
- `_fromLegado()` — Legado JSON → VideoSource 映射
- `_toLegado()` — VideoSource → Legado JSON 映射

#### 源测试
- `testSource(index)` — HTTP GET 请求 apiUrl，10 秒超时，更新 status 和 respondTime
- `testAllSources()` — 逐个测试所有源

#### 订阅管理
- `addSubscription(sub)` — 添加订阅（按 URL 去重）
- `removeSubscription(index)` — 删除订阅
- `updateSubscription(index, sub)` — 更新订阅
- `syncSubscription(url)` — HTTP GET 获取 JSON，调用 `importSources(merge: true)`
- `syncAllSubscriptions()` — 逐个同步所有订阅

---

### 3.3 页面层 (`lib/pages/sources/`)

#### SourcesPage (`sources_page.dart`)
- **AppBar**：标题"源管理"、搜索按钮、排序下拉菜单（6种排序）、更多菜单（添加/测试全部/导入/导出/订阅）
- **筛选栏**：状态筛选 Chip（全部/活跃/禁用/错误）、分组下拉筛选
- **源列表**：`ListView.builder` 渲染过滤后的源列表，每项显示名称/URL/状态标签/分组/响应时间
- **操作菜单**：选择/编辑/测试/删除
- **对话框**：添加源、导入源（合并/替换模式）、导出源、订阅管理

#### SourceEditPage (`source_edit_page.dart`)
- **Tab 1 基础信息**：名称、URL、分组（自动完成）、权重、NSFW 开关
- **Tab 2 高级配置**：解析地址、自定义请求头、备注、只读信息展示
- **Tab 3 规则配置**：搜索规则区、列表页规则区（8个选择器字段）、详情/播放规则区（4个字段）

---

### 3.4 规则解析 (`lib/utils/source_parser.dart`)

**SourceParser** 封装 FFI 调用，提供 HTML 内容解析能力。

#### 数据类
- `ParsedVideoItem`：name/url/cover/year/area/type/score/desc
- `ParsedPlayItem`：name/url

#### 核心方法
- `parseList(content, baseUrl)` — 解析视频列表，使用 `LegadoAnalyzer.getElements()` 按 `ruleList` 选择器提取列表项
- `parseDetail(content, baseUrl)` — 解析详情页，返回 `(desc, plays)` 元组
- `parseSearch(content, baseUrl)` — 解析搜索结果，有独立 `ruleSearchList` 时使用，否则回退到 `parseList`
- `getSearchUrl(keyword)` — 将 `{keyword}` 替换为 URL 编码的关键词
- `_extractText()` — 统一的文本提取方法，自动处理 `@` 语法

---

### 3.5 FFI 绑定 (`lib/ffi/`)

底层使用 Go 编译的 `legado_ffi.dll` 动态库，提供 26 个 C 函数绑定。

#### 高层封装类
- `LegadoLog` — 日志管理
- `LegadoAnalyzer` — HTML 内容解析引擎（含 Finalizer 自动释放）
- `LegadoRuleData` — 键值对变量存储
- `LegadoJS` — 嵌入式 JavaScript 引擎
- `LegadoURL` — URL 解析器

## 四、数据流

```
VideoSource/SourceRule/SourceSubscription (模型)
          |
          v
     SourceState (聚合状态)
          |
          v
     SourceStore (Zustand Store + Hive 持久化)
          |
          +---> SourcesPage (列表/搜索/筛选/导入导出/订阅)
          +---> SourceEditPage (编辑/规则配置)
          +---> SourceParser -> LegadoAnalyzer (FFI HTML 解析)
```
